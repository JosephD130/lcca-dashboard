# Design canvas: the Summary sheet as a dashboard

Source for the published design canvas at
https://claude.ai/code/artifact/8737d07a-9a78-4b05-aab6-5e4140172752

Two pages.

**Summary as a dashboard** carries one artboard, `SummaryDashboard.dc.html`: the whole
Summary sheet drawn as a dashboard, top to bottom. Six KPI tiles, the results table with
bars inside the present-worth column, the locator map and the Google Earth export in one
card, the RealCost comparison block, the seven charts on a two-column grid with the
unit-cost benchmark in the eighth cell, and the pavement-section read-back.

**Where the map goes** carries the placement study that came before it: option A (the
header card, which is what the workbook now does), option A+ (the same placement read as
a dashboard), option B (a full-width band) and the map on its own.

Every number and every chart on the dashboard artboard comes from the McKellar-Sipes (MKL)
example run in `verification/examples/MKL_Runway2-20`, generated by `make_dashboard.py`,
so the artboard cannot drift from what the sheet actually produces. Two things on it are
proposals rather than current behavior: chart 1's five categories use one light-to-dark
ramp instead of the workbook's mixed greys, and the unit-cost benchmark is new.

| File | Artboard |
|---|---|
| `SummaryDashboard.dc.html` | The whole Summary sheet, read as a dashboard (generated) |
| `Main.dc.html` | A. Header card, the option that was built |

| `OptionB.dc.html` | B. Full-width band |
